----------------------------------
Paint Save File Format Version 1.0
----------------------------------

The Paint Save File Format allows the serialization
of a users Paint creation into a plain text file.

---------
Circle
---------
A circle block looks like the following. Features
are all required and appear in the specified order.

------------------ START EXAMPLE -----------------
Circle
	color:36,18,161
	filled:false
	center:(62,102)
	radius:52
End Circle
------------------ END   EXAMPLE -----------------

where center is the center of the circle.

A couple of restrictions are placed on what can be done with the variables:
    - color: the color variable should be composed of 3 integers, which range from 0 to 255. These colors correspond to
             the red, green and blue hue the color should have.

             Here are examples of what the color variable should have:
------------------ START EXAMPLE -----------------
    color:25,124,1
    color:0,0,0
    color:255,255,255
------------------ END   EXAMPLE -----------------
             Here are the examples of what the color variable should not look like:
------------------ START EXAMPLE -----------------
    color: -25,124,1
    color:0,0,0.2
    color:252,256,255
    color:252,256,abc
------------------ END   EXAMPLE -----------------
    - filled: a variable which represents whether the circle should be filled or not. As such, the filled variable
              should only have either true or false as its input string.

              Here are the two examples of what the filled variable should be:
------------------ START EXAMPLE -----------------
    filled:true
    filled:false
------------------ END   EXAMPLE -----------------
              Here are the two examples of what the filled variable should not be:
------------------ START EXAMPLE -----------------
    filled:True
    filled:9
    filled:momomm
    filled:
------------------ END   EXAMPLE -----------------
    - center: center is a Point object, which is represented as (x, y), for some integers x,y. Note that x,y can be negative,
          zero, or positive. It represents the center point of the Circle.

          It should always be in the form of p1:(x,y), where x,y are integers. x,y cannot be any string with characters,
          nor can it be a decimal value (i.e. it cannot be a fraction, nor an irrational number). It should also just be
          an integer, not an expression nor an equation.

          Here are the examples of what the center variable should be:
------------------ START EXAMPLE -----------------
    center:(1,2)
    center:(102,-2123)
    center:(-12,-14)
    center:(-10,23)
    center:(0,0)
    center:(102,23)
    center:(-14,-213)
------------------ END   EXAMPLE -----------------
          Here are the examples of what the center variable should not be:
------------------ START EXAMPLE -----------------
    center:(,2)
    center:(102,)
    center:(-12,a)
    center:(-b,23)
    center:(+0,--0)
    center:(102+20,23-2)
    center:(-14,-213+a)
    center:-14,1
------------------ END   EXAMPLE -----------------
    - radius: radius is an integer which describes the radius of the circle. This integer should always be a
              non-negative integer.

              Here are some examples of what the radius variable could be:
------------------ START EXAMPLE -----------------
    radius:2
    radius:0
    radius:22
    radius:12
    radius:4
------------------ END   EXAMPLE -----------------
              Here are some examples of what the radius variable cannot be:
------------------ START EXAMPLE -----------------
    radius:-2
    radius:0.2
    radius:25.2222
    radius:hi
    radius:
------------------ END   EXAMPLE -----------------
--------------
Circle Summary
--------------
In general, a Circle should follow the format as displayed above. It should also be following the general format
described earlier. As such, there should be no extra things such as comments, typos, etc.
