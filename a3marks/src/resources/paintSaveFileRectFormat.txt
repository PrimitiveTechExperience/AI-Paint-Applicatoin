----------------------------------
Paint Save File Format Version 1.0
----------------------------------

The Paint Save File Format allows the serialization
of a users Paint creation into a plain text file.

---------
Rectangle
---------
A rectangle block looks like the following. Features
are all required and appear in the specified order.

------------------ START EXAMPLE -----------------
Rectangle
	color:36,18,161
	filled:false
	p1:(62,102)
	p2:(138,110)
End Rectangle
------------------ END   EXAMPLE -----------------

where p1 and p2 are two corners of the rectangle.

A couple of restrictions are placed on what can be done with the variables:
    - color: the color variable should be composed of 3 integers, which range from 0 to 255. These colors correspond to
             the red, green and blue hue the color should have.

             Here are examples of what the color variable should have:
------------------ START EXAMPLE -----------------
    color:25,124,1
    color:0,0,0
    color:255,255,255
------------------ END   EXAMPLE -----------------
             Here are the examples of what the color variable should not look like:
------------------ START EXAMPLE -----------------
    color: -25,124,1
    color:0,0,0.2
    color:252,256,255
    color:252,256,abc
------------------ END   EXAMPLE -----------------
    - filled: a variable which represents whether the rectangle should be filled or not. As such, the filled variable
              should only have either true or false as its input string.

              Here are the two examples of what the filled variable should be:
------------------ START EXAMPLE -----------------
    filled:true
    filled:false
------------------ END   EXAMPLE -----------------
              Here are the two examples of what the filled variable should not be:
------------------ START EXAMPLE -----------------
    filled:True
    filled:9
    filled:momomm
    filled:
------------------ END   EXAMPLE -----------------
    - p1: p1 is a Point object, which is represented as (x, y), for some integers x,y. Note that x,y can be negative,
          zero, or positive. It represents the top left point of the rectangle.

          It should always be in the form of p1:(x,y), where x,y are integers. x,y cannot be any string with characters,
          nor can it be a decimal value (i.e. it cannot be a fraction, nor an irrational number). It should also just be
          an integer, not an expression nor an equation.

          Here are the examples of what the p1 variable should be:
------------------ START EXAMPLE -----------------
    p1:(1,2)
    p1:(102,-2123)
    p1:(-12,-14)
    p1:(-10,23)
    p1:(0,0)
    p1:(102,23)
    p1:(-14,-213)
------------------ END   EXAMPLE -----------------
          Here are the examples of what the p1 variable should not be:
------------------ START EXAMPLE -----------------
    p1:(,2)
    p1:(102,)
    p1:(-12,a)
    p1:(-b,23)
    p1:(+0,--0)
    p1:(102+20,23-2)
    p1:(-14,-213+a)
    p1:-14,1
------------------ END   EXAMPLE -----------------
    - p2: p2 is a Point object, which is represented as (x, y), for some integers x,y. Note that x,y can be negative,
          zero, or positive. It represents the bottom right point of the rectangle.

          p2 follows the same formatting as the p1 variable. It should always be in the form of p1:(x,y),
           where x,y are integers. x,y cannot be any string with characters, nor can it be a decimal value
           (i.e. it cannot be a fraction, nor an irrational number). It should also just be
           an integer, not an expression nor an equation.

-----------------
Rectangle Summary
-----------------
In general, a rectangle should follow the format as displayed above. It should also be following the general format
described earlier. As such, there should be no extra things such as comments, typos, etc.
